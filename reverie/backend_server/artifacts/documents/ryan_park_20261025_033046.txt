Overview  
This document records the technical decisions made during the current phase of the mobile app’s development, with a focus on navigation, user flow, and cross-device consistency. The goal is to establish a reliable foundation for the next iteration while maintaining flexibility for future enhancements.

Navigation and User Flow  

The app uses a unified bottom navigation bar containing five primary sections: Home, Profile, Settings, Support, and Account. The Home section is the default landing page. Users begin by selecting a category, which filters the content and routes them to the appropriate section.
