Security Fixes

All user inputs were validated against expected formats and types before being processed.  
Sensitive fields were sanitized to prevent injection attacks.  
Out-of-bounds array access was corrected, and unsafe file paths were replaced with validated paths.  

2. Authentication and Authorization  
Session tokens were refreshed securely and no longer retained in memory after successful authentication.  
Access controls were updated to enforce role-based permissions and prevent unauthorized access.
