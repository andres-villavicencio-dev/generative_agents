Technical decisions to document

2. Store user preferences in IndexedDB with a fallback to local storage for offline access.
3. Keep the authentication flow simple: verify the token, then route the user to the appropriate screen.
4. Use a consistent error-handling pattern across the app, with clear user feedback and retry logic.
5. Add a basic analytics layer that collects usage events without exposing sensitive data.
6. Document the migration strategy for the old data schema, including rollback steps.
