Adam Smith built the Smith-Craft Smart Urban System (SCSUS), a modular, city-scale planning and engineering platform designed to improve public services through intelligent collaboration. The system consists of distributed decision-making nodes, real-time data sensors, and a visual coordination interface. Each node can receive requests from residents, businesses, or civic groups, analyze available resources, and propose optimized solutions. The central server stores these proposals, ranks them, and allows local representatives to select a shared plan. The interface provides an interactive map, timeline, and voting tool so the public can see progress without needing technical expertise.

The SCSUS uses metal frames and reinforced polymer panels for its nodes and wireless sensors, fiber-optic cables, and solar panels for connectivity and power. Its design avoids traditional, centralized control because every decision-maker has an independent voice, while the shared interface ensures transparency.

Smith made the system to challenge the idea that planning is solely the job of elected officials. He believed that creativity should be distributed across citizens and civic groups, giving everyday people a meaningful role in shaping the city’s future. The SCSUS works by combining democratic participation with data-driven analysis, making it possible for a community to develop, test, and adapt a plan before implementation.
